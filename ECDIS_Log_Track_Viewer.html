ECDIS Log Track Viewer

Sperry Marine ECDIS kayıtlarından seçilen zaman aralığındaki gemi izini görüntüler ve yazdırır. / Displays and prints the own-ship track for a selected interval from Sperry Marine ECDIS logs. Tüm işlem tarayıcıda yerel olarak yapılır; kaynak dosya bir sunucuya yüklenmez.

01 / Kayıt kaynağı Log source

Choose a Sperry Marine ECDIS log source

Henüz kaynak seçilmedi. / No source selected.
ZIP paketini doğrudan veya paketin açılmış klasörünü kullanabilirsiniz. / Use the exported ZIP package directly or select its extracted folder.
Kaynak seçildiğinde CCRS kayıtları taranır ve kullanılabilir zaman aralığı belirlenir. / CCRS records will be scanned after a source is selected.

02 / Zaman ve görüntüleme Time & display

Log zaman damgaları UTC tabanında yorumlanır. Yerel seçim = UTC + seçilen ofset. / Log timestamps are interpreted on a UTC basis. Local selection = UTC + selected offset.
Saat dilimi ve kaynak seçildiğinde yerel seçimin karşılık geldiği UTC log aralığı burada gösterilir. / UTC log interval corresponding to the local selection will be shown here.
Varsayılan / Default: 20 kn.

Sperry Marine VisionMaster FT - DataLog Export

System → Diagnostics → DataLog → Export

Türkçe

  1. VisionMaster FT ekranında System menüsünü açın.
  2. Diagnostics bölümüne girin.
  3. DataLog sekmesini açın.
  4. Kullanmak istediğiniz kayıt aralığını seçin; mevcut yazılım sürümünde sunulan seçim/filtre alanlarını kullanın.
  5. Export komutuyla kayıt paketini USB bellek veya uygun hedef klasöre aktarın.
  6. Bu uygulamada dışa aktarılan ZIP dosyasını doğrudan seçebilir veya ZIP'i açıp KLASÖR SEÇ seçeneğiyle açılmış klasörü gösterebilirsiniz.
Not: VisionMaster FT sürümüne ve sistem yapılandırmasına göre menü görünümü veya seçeneklerin adı küçük farklılıklar gösterebilir. Bu uygulamanın rota kaynağı CCRS log kayıtlarıdır.

English

  1. Open the System menu on the VisionMaster FT display.
  2. Open Diagnostics.
  3. Select the DataLog tab.
  4. Select the required log interval using the controls available in your installed software revision.
  5. Use Export to copy the log package to approved removable media or a destination folder.
  6. In this viewer, select the exported ZIP directly, or extract it and use CHOOSE FOLDER.
Note: Menu presentation and available controls may vary slightly with VisionMaster FT software revision and configuration. CCRS log records are the primary track source used by this viewer.
Removable media / Harici medya: Sperry Marine's manual cautions that USB or other external media should be scanned with up-to-date antivirus/malware protection before connection to a VisionMaster PC and, where practicable, reserved for VisionMaster use.
Reference: Northrop Grumman Sperry Marine B.V., VisionMaster FT Ship's Manual, Volume 2 - Configuration & Commissioning, Part No. 65900011V2-12, Rev. A (2014). The manual confirms Diagnostics/DataLog availability and CCRS/DataLog configuration. The exact Export step above reflects the operating workflow used with the installed system.
