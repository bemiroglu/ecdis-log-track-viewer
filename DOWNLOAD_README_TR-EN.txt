ECDIS LOG TRACK VIEWER — v3.16 RC
====================================

TÜRKÇE
------
ÖNERİLEN İNDİRME:
https://github.com/bemiroglu/ecdis-log-track-viewer/archive/refs/heads/main.zip

1. ZIP'i normal bir klasöre çıkarın.
2. ECDIS_Log_Track_Viewer.html dosyasını güncel Chrome, Edge veya Firefox sınıfı bir browser ile açın.
3. Sperry Marine VisionMaster FT DataLog paketini ZIP SEÇ ile veya çıkarılmış klasörü KLASÖR SEÇ ile açın.
4. Varsayılan yerel saat dilimi UTC+03:00 Türkiye'dir.
5. YAZDIR / YOĞUN YAZDIR için A4 Yatay kullanın.
6. Ayrıntılı online altlık OpenFreeMap/MapLibre kullanır; erişilemezse gömülü coastline fallback devrede kalır.
7. Bu araç ECDIS veya seyir karar sistemi değildir; harita altlığı seyir haritası değildir.

ENGLISH
-------
RECOMMENDED DOWNLOAD:
https://github.com/bemiroglu/ecdis-log-track-viewer/archive/refs/heads/main.zip

1. Extract the ZIP to a normal folder.
2. Open ECDIS_Log_Track_Viewer.html in a current Chrome, Edge or Firefox-class browser.
3. Open the exported Sperry Marine VisionMaster FT DataLog package with CHOOSE ZIP, or select the extracted directory with CHOOSE FOLDER.
4. Default local time offset is UTC+03:00 (Türkiye).
5. Use A4 Landscape for PRINT / DENSE PRINT.
6. Detailed online mapping uses OpenFreeMap/MapLibre; the embedded coastline fallback remains available if it cannot load.
7. This utility is not an ECDIS or navigation decision system; the basemap is not a navigational chart.
